# CSC3700-Project
Building a full-stack web application across three milestones this semester. The application is an Aurora CS Course Scheduler, a tool that displays the Computer Science course catalog.

Run Procedure:

1. Download All files under Course-Scheduler
2. Start json server using "npx json-server --watch db.json --port 3333" in db directory
3. run npm install in src directory
4. run npm run dev in src directory
